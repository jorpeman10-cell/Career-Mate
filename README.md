# Career-Mate 职业管家

AI-Native 个人职业管理系统：对话即管理，数据主权在本地。

**在线简历页**（GitHub Pages）：https://jorpeman10-cell.github.io/Career-Mate/

## 组成部分

- **Talent Object**：结构化职业档案（经历/技能/证据台账），主副本在本人本地
- **简历页**（`docs/index.html`）：双语静态页，可证伪词条 + 证据三级标记（✓专家核验 / ◐作品可查 / ○本人自述）
- **职业管家工作台**：本地操作台（机会甲板 / 档案编辑 / 技能矩阵 / 备份 / 操作日志）
- **对外问答协议**：匿名公开层 → 令牌解锁 NDA → 一次性实名揭示，全程审计

## 更新简历页

修改本地 Talent Object 后重新生成 `page.html`，覆盖 `docs/index.html` 并 push 即可更新线上版本。
